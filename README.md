## Featured projects

**[ad-measurement-lab](https://github.com/PraneethKorukonda/ad-measurement-lab)**: ad incrementality, brand lift, Bayesian marketing mix modeling and reserve-price auctions, benchmarked against Criteo's 14M-user randomized ad test and simulated ground truth.

**[causallab](https://github.com/PraneethKorukonda/Causal-Inference)**: A/B testing and causal inference toolkit (CUPED, sequential testing, propensity methods, doubly robust estimation, DiD, synthetic control, RD, IV), with every estimator validated against known answers, including the LaLonde experiment. 246 tests.

**[Autonomous Financial Agent](https://github.com/PraneethKorukonda/Autonomus-Financial-Agent)**: LangGraph researcher and critic agents that answer questions about SEC 10-K filings using retrieval and web search, with the critic sending unsupported claims back for revision.

**[Amazon Reviews Sentiment Analysis](https://github.com/MLOps-Group-3/Amazon-Reviews-Sentiment-Analysis)** (team): end-to-end MLOps pipeline for review sentiment with BERT/RoBERTa, Airflow, DVC, MLflow, Docker and GCP.

**[Customer-Centric Marketing](https://github.com/AlgoDM-Fall2023-Team6/Data-Driven-Customer-Centric-Marketing)** (team): RFM segmentation, next-purchase-date prediction and daily sales forecasting, served as Streamlit apps.

## What I work on

| Area | Methods |
|---|---|
| Experimentation | A/B test design, power and MDE, SRM checks, CUPED, sequential testing (mSPRT, group sequential), Bayesian A/B, multi-armed bandits |
| Causal inference | Propensity scores, matching, IPW, doubly robust (AIPW, TMLE), difference-in-differences, synthetic control, regression discontinuity, instrumental variables, sensitivity analysis |
| Marketing measurement | Incrementality and lift tests, brand lift, geo experiments, Bayesian MMM, uplift modeling (meta-learners, causal forests) |
| Machine learning | Gradient boosting, NLP (BERT, RoBERTa), CLIP image search, forecasting |
| GenAI | Multi-agent systems, RAG, LLaMA 2 on AWS Bedrock |
